# auth_flexaccess

Moodle authentication plugin for target-aware flexible access. It owns temporary-user and authenticated-user lifecycle, quick registration, activation tokens and a throttled task-based mail queue.

It provides temporary-user and authenticated-user lifecycle, quick registration, activation tokens and a throttled task-based mail queue. Maturity: Beta (0.9.x).

Requires Moodle 4.5+.
